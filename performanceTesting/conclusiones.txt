5. LIMITATIONS AND CONSIDERATIONS
==================================================

The following limitations should be considered when interpreting the results:

- The assessment evaluates only the FakeStore API authentication endpoint.

- Results represent the specific execution environment, network conditions, and API availability at the time of testing.

- The test uses 20 concurrent virtual users and a 60-second scheduled execution. It does not establish the maximum capacity of the API.

- External service availability and network latency may influence performance measurements.

- The JTL evidence does not independently identify which individual CSV username was consumed by each request. Although five unique credentials are configured in the CSV, individual credential consumption cannot be demonstrated from the current JTL evidence.

- The test focuses on the official performance acceptance criteria and does not constitute a comprehensive security, endurance, stress, or scalability assessment.
